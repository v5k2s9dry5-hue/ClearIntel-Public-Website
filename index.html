      03 / METHODOLOGY

      A conclusion is only as useful as the evidence behind it.

      ClearIntel separates strong source matches from leads that still need checking. Ratings apply to individual pieces of evidence, not to someone's identity or to the truth of every claim on a page.

      Illustrative grading framework. Actual client findings require source review and an explicitly defined research scope.

      HOW EVIDENCE IS READ
      GRADE 03 / STRONG MATCH

      Exact identifier or identical file

      A public register number exactly matches the identifier searched, or two files have the same cryptographic hash. The specific match is strong, but context still matters.

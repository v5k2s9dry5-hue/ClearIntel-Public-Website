# ClearIntel roadmap — updated 22 November 2026

Project: [ClearIntel public website](https://clearintel-public.onrender.com/) · GitHub repository: `v5k2s9dry5-hue/ClearIntel-Public-Website`.

This is the **public, lawful public-source product**, separate from the private Ubuntu/WSL investigation engine. Roadmap items are plans, not promises of real-time/complete coverage or independently verified events.

## Non-negotiable constraints

- **£0 additional cost** by default. Prefer existing Render free plan, licensed/free dependencies, and no new paid infrastructure or API subscriptions without explicit approval.
- Never publish or collect private case data, addresses of private individuals, keys, investigation files or sensitive user queries in this public repository.
- Preserve original-source links, publication/first-seen times, freshness, source coverage, and uncertainty. No invented event positions or claims of corroboration.
- Military aviation and naval layers contain **source-linked historical reports of completed events**, not live tracking.
- Accessible, easy-to-understand default mode; optional analyst depth. Test desktop/mobile and API failure paths before each merge.
- Accounts, subscriptions, payment infrastructure and native mobile applications remain deferred until the public core is stable.

## NEW flagship: Intelligence Replay (approved for roadmap 22 November)

**Goal:** Let a researcher reconstruct the *observed evolution of a developing story* across public-source reports, rather than just read the most recent headline.

### Replay R0 — £0 browser-local prototype (after current reliability work)

- Add a user-initiated **Save snapshot** action for public news results. Keep a bounded history for the current browser, without accounts, server storage or background data collection.
- Snapshots record **observed-at UTC**, search term and time window, original linked headline, publisher, provider, and supplied feed/first-seen timestamp. An observed-at time is **not** the event occurrence time.
- Offer a replay control to view only **actually saved** snapshots; explain when no earlier snapshot exists. Never fabricate back history or quietly substitute current results for historical results.
- Explicitly label all results as unverified reporting leads. Separate observation time, publication time and reported event time where available.
- Include a local **Clear history** control and document how long browser data persists. Use bounded quotas and conservative content lengths, avoid personal data storage, and ensure no snapshots sync to the server.
- Desktop/mobile and accessibility tests, including empty history, repeated identical snapshots, browser-storage denial and deletion.

### Replay R1 — source evolution (after trustworthy R0)

- Show which headlines first appeared, remained, disappeared or were changed between **saved observations** (not universal media coverage).
- Detect likely duplicate / syndicated articles using explicit, explainable source-link and text similarity. Do **not** equate ten near-identical copies with ten independent confirmations.
- Surface source corrections or contradictions as **potential** differences needing human review; preserve links and timestamps.

### Replay R2 — richer intelligence and exports (later phase)

- Bounded timeline filtered by country or topic; optionally compare periods and export replay history with source citations and caveats.
- Only consider server-side long-term retention with clear user consent, privacy review, abuse controls, lawful processing, capacity planning and an explicit cost decision.
- Do not ingest historical stories from elsewhere and present them as having been observed by ClearIntel at an earlier time.

### Acceptance criteria

- A replay only includes snapshots saved after the feature was enabled and actually captured.
- A user can distinguish `observed_at_utc`, `feed_time_utc` and `incident_time_utc` at every relevant view.
- Source and comparison errors do not erase previously saved valid snapshots.
- Browser-local replay works without paid API services or exposure of private ClearIntel investigations.
- All historical claims are backed by retained source references; the feature never asserts that a publication proves an incident.
